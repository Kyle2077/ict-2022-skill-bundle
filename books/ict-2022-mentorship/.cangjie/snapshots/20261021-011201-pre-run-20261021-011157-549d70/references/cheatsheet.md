# 决策规则速查 — 开启ICT 2022导师计划的成功之门 / Unlocking Success in ICT 2022 Mentorship

| 能力 | 一句话规则 |
|---|---|
| 交易时段与禁忌日过滤 | 先查五 Killzone 窗口与禁忌日/亚洲区间硬门，再允许任何入场分析 |
| 每日静态价位锚计算 | 盘前算出 PDH/PDL、NMO/NYO、Asian range、CBDR 中点等不随盘中变化的参考线 |
| 流动性分类与 DOL 识别 | ERL 与 IRL 交替：扫完旧高低下一站是不平衡，回补完不平衡下一站是旧高低 |
| 日线偏向判定检查清单 | 折溢价位置→DOL 同向核对→PDH/PDL 反应修正→SMT 可选确认，输出带依据链的偏向 |
| MSS/结构突破有效性判定 | 越位+有力收盘+留下FVG+叙述自洽才算有效 MSS；无位移=反向信号 |
| FVG 三蜡烛判定 | 三蜡烛空档即 FVG：bearish=[c3高,c1低]，bullish=[c1高,c3低]，抵消即非 FVG |
| PD Array/Block 类型识别词典 | 七类 Block 各有结构指纹与有效性条件；MB=失败摆动、BB=成功摆动 |
| 高概率入场检查清单与止损止盈参数 | 硬门（方向/CBDR/Asian/禁忌/回撤门）不过不交易；入场八类枚举；止损六档止盈七路查表 |
| NY Scalp 九步流程 | 伦敦确认后 7:00 起等 7-10 点回撤，9:00 前未形成即放弃；形成则 62% Fib 入场 |
| ICT 2022 Model 六步执行流程 | 扫流动性→位移FVG→MSS→50%Fib→FVG位置→折价限价；新闻日叠加9步观察与5/10点风控 |
| OTE 入场区计算 | 位移后按方向锚定 Fib，输出 0.62-0.79 区与 0.705 甜蜜点作限价带 |
| Turtle Soup/Stop Run 与 Failure Swing 入场 | 扫止损后V型收回→短期结构断点回测入场；无扫掠则走 failure swing 备选路径 |
| PO3/AMD 节奏状态机 | 积累→操纵→分配；盘整后只能接扩张；确认需MSS+回到NMO另一侧；新闻日改写Judas时间表 |
| SMT 背离确认工具 | 相关品种在预定水平的极值裂缝=对既有想法的绿灯/红灯，绝不单独入场 |
| Top Down 分析与 15m→5m 执行工作流 | 月周日定局→4H/1H划折溢价→15m标注→只在5m入场；8:30-12:00执行、11:00前建仓目标 |
